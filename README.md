## 📖 项目介绍

PixelVerse 是一款模仿 Wplace / Reddit r/place 的多人在线像素画布项目。
支持多房间模式，多人可以在画布上自由放置像素方块，实时同步所有人绘画操作，共同创作像素画作。

- ✨ **多房间多人实时涂鸦**，支持自行创建房间
- 📈 完整等级系统，升级解锁更高涂色点上限
- 🏆 右上角排行榜，展示涂鸦贡献前 10 名玩家
- 🎁 每日签到系统，领取涂鸦币与涂鸦点
- 🛒 内置商店，消耗涂鸦币兑换各类道具
- 🖼️ 超大画布，自由涂鸦创作
- 🚀 轻量 Node.js + MySQL 后端，部署简单快速
- 📦 开箱即用：内置网页安装向导，首次启动填表即可完成建库与后台初始化
- 🔧 邮件发信设置后置到后台，无需改配置文件

## 🎮 玩法说明

> 每 10 秒新增一个涂鸦点，挂机可获得
>
> ⚠️ 请勿绘画任何违法乱纪图案，如出现违规内容，必要时将配合公安机关处理。

### 🏠 房间系统

支持多房间多人在线实时涂鸦；玩家可以自主创建房间，**创建房间需要消耗开房卡**。

### 📊 等级与涂色点系统

最高等级为 **9 级**，涂鸦点数累计提升等级，等级越高涂色点上限越高；每升一级涂鸦币奖励在上一级基础上 +20。

| 等级 | 升级所需累计涂鸦 | 涂色点上限 | 升级涂鸦币奖励 |
|---|---|---|---|
| 1 | 初始 | 60 | 无 |
| 2 | 50 | 75 | 100 |
| 3 | 100 | 95 | 120 |
| 4 | 300 | 120 | 140 |
| 5 | 600 | 150 | 160 |
| 6 | 1200 | 185 | 180 |
| 7 | 2400 | 215 | 200 |
| 8 | 4800 | 260 | 220 |
| 9 | 8000 | 300 | 240 |

### 🏆 排行榜

页面右上角内置排行榜面板，展示涂鸦数量排名前 10 的用户。

### 📅 每日签到

右上角签到按钮，**每日仅可签到一次**

- 随机获得：20‑50 涂鸦币
- 随机获得：20‑30 涂鸦点

### 🛒 商店系统

右上角商店按钮打开商店，使用涂鸦币兑换道具：

1. 涂鸦点上限：`1 涂鸦币 = 1 涂色上限`
2. 临时涂鸦点：`1 涂鸦币 = 10 临时涂鸦点`
3. 开房卡：`1000 涂鸦币`，用于创建新房间

## 🛠️ 环境要求

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Node.js | 推荐 v20.20.2 | 也可使用 v18+ |
| MySQL | 推荐 8.0 | 必须，用于存储画布/用户/房间等数据 |

> ⚠️ 本项目**必须依赖 MySQL**。若使用 MySQL 8.0，安装向导使用的账号需具备 `CREATE DATABASE` 权限（如 `root`）。普通业务账号（如 `qypixel`）通常无建库权限，不能用于首次安装。

## 📥 安装部署

### 1. 拉取代码

```bash
git clone https://github.com/2692643871/PixelVerse---Wplace-.git
cd PixelVerse---Wplace
```

### 2. 安装依赖

```bash
npm install
```

### 3. 准备数据库账号

确保有一台可访问的 MySQL 服务，并准备好一个**具有建库权限**的账号（首次安装向导将用它自动创建数据库与数据表）。

- 数据库名、账号、密码在安装向导中填写，无需提前手动建库。
- 若仅连接已有库，确保该账号对目标库有完整权限即可。

### 4. 启动服务（进入安装向导）

**不要**预先创建 `.env`、也**不要**手动配置数据库连接——直接启动服务，由网页向导完成初始化：

```bash
node server.js
```

启动成功后，服务监听默认端口 `3000`（可在 `server.js` 顶部或 `.env` 修改）。

### 5. 网页安装向导（首次必做）

浏览器访问安装向导：

```
http://你的服务器IP:3000/install.html
```

> 若直接访问 `/` 或 `/admin/`，未完成安装时会自动跳转到安装页面。

在安装页面填写：

| 字段 | 说明 |
|---|---|
| 数据库主机 | 通常 `127.0.0.1` |
| 数据库端口 | 通常 `3306` |
| 数据库名 | 自定义，如 `qypixel` |
| 数据库账号 | 具备建库权限的账号（如 `root`） |
| 数据库密码 | 该账号密码 |
| 后台管理员账号 | 登录后台用的账号 |
| 后台管理员密码 | 登录后台用的密码 |

点击「开始安装」后，系统将：

1. 用你填写的 MySQL 账号连接并自动 **CREATE DATABASE**；
2. 创建全部数据表（用户、房间、画布像素、画迹日志、商店流水、设置等）；
3. 写入后台管理员账号；
4. 自动生成 `.env`（含 `INSTALLED=1`）；
5. 跳转至后台登录页。

> 💡 之后想重新走安装向导，只需删除项目根目录的 `.env` 文件（或删除其中 `INSTALLED=1` 一行），重启服务即可再次进入。

### 6. 访问网页

```
http://你的服务器IP:3000
```

进入像素涂鸦画布。后台管理地址：

```
http://你的服务器IP:3000/admin/
```

### 7. 邮件发信设置（验证码注册用）

登录后台后，在 **全局设置 → 邮件设置** 中填写：

- 发信邮箱账号（QQ 邮箱，如 `123@qq.com`）
- SMTP 授权码（QQ 邮箱的 SMTP 授权码，非登录密码）

填写后**先点「保存邮件设置」，再点「发信测试」** 验证能否正常发送验证码邮件。
该配置存储于数据库 `settings` 表，运行时动态读取，无需改配置文件或重启服务。

## 🚀 服务器部署

### 方式 1：直接前台 / 后台运行

```bash
node server.js
```

后台常驻（Linux，断开 SSH 不退出）：

```bash
nohup node server.js > server.log 2>&1 &
```

### 方式 2：PM2 守护进程（推荐生产环境）

```bash
# 安装 pm2（如未安装）
npm install pm2 -g

# 用项目自带配置启动（eco.config 已配置好）
pm2 start ecosystem.config.js

# 设置开机自启
pm2 startup
pm2 save
```

常用命令：

```bash
pm2 ls          # 查看进程
pm2 logs        # 查看日志
pm2 restart all # 重启
pm2 stop all    # 停止
```

### 方式 3：宝塔面板部署

参考文档：`deploy-baota.md`

大致流程：宝塔创建网站 → 放代码 → 安装依赖 → `node server.js` 或 PM2 守护 → 放行端口 / 配置反向代理。

## 📝 注意事项

1. **必须配置 MySQL**：项目依赖 MySQL 存储数据，未安装或连接失败将无法启动。
2. **首次安装需建库权限**：安装向导使用的 MySQL 账号要有 `CREATE DATABASE` 权限（如 `root`）。
3. **端口与防火墙**：默认端口 `3000`，可在 `server.js` 或 `.env` 修改；公网部署请放行对应端口与安全组。
4. **数据持久化**：画布像素、用户、房间、等级、涂鸦币、签到等全部存入 MySQL，重启服务不会丢失。
5. **重新安装**：删除根目录 `.env` 或其中 `INSTALLED=1`，重启服务即可再次进入安装向导。
6. **HTTPS 建议**：公网部署建议配置反向代理（Nginx / 宝塔）+ SSL 证书，实现 HTTPS 访问。
7. **后台路径变更**：后台入口已从 `admin.html` 改为 `admin/` 目录，旧链接 `admin.html` 会自动 302 重定向到新地址。
8. **`.env` 安全**：`.env` 含数据库与后台密码，**切勿提交到公开代码仓库**（已在 `.gitignore` 忽略）。
