## 📖 项目介绍
PixelVerse是一款模仿 Wplace / Reddit r/place 的多人在线像素画布项目。
支持多房间模式，多人可以在画布上自由放置像素方块，实时同步所有人绘画操作，共同创作像素画作。

- ✨ **多房间多人实时涂鸦**，支持自行创建房间
- 📈 完整等级系统，升级解锁更高涂色点上限
- 🏆 右上角排行榜，展示涂鸦贡献前10名玩家
- 🎁 每日签到系统，领取涂鸦币与涂鸦点
- 🛒 内置商店，消耗涂鸦币兑换各类道具
- 🖼️ 超大画布，自由涂鸦创作
- 🚀 轻量 Node.js 后端，部署简单快速
- 📦 开箱即用，少量依赖，快速搭建私有涂鸦画布

## 🎮 玩法说明
> 每10秒新增一个涂鸦点，挂机可获得
> ⚠️ 请勿绘画任何违法乱纪图案，如出现违规内容，必要时将配合公安机关处理。

### 🏠 房间系统
支持多房间多人在线实时涂鸦；玩家可以自主创建房间，**创建房间需要消耗开房卡**。

### 📊 等级与涂色点系统
最高等级为 **9级**，涂鸦点数累计提升等级，等级越高涂色点上限越高；每升一级涂鸦币奖励在上一级基础上+20。

|等级|升级所需累计涂鸦|涂色点上限|升级涂鸦币奖励|
|---|---|---|---|
|1|初始|60|无|
|2|50|75|100|
|3|100|95|120|
|4|300|120|140|
|5|600|150|160|
|6|1200|185|180|
|7|2400|215|200|
|8|4800|260|220|
|9|8000|300|240|

### 🏆 排行榜
页面右上角内置排行榜面板，展示涂鸦数量排名前10的用户。

### 📅 每日签到
右上角签到按钮，**每日仅可签到一次**
- 随机获得：20‑50 涂鸦币
- 随机获得：20‑30 涂鸦点

### 🛒 商店系统
右上角商店按钮打开商店，使用涂鸦币兑换道具：
1. 涂鸦点上限：`1涂鸦币 = 1涂色上限`
2. 临时涂鸦点：`1涂鸦币 = 10临时涂鸦点`
3. 开房卡：`1000涂鸦币`，用于创建新房间

## 🛠️ 环境要求
- Node.js 推荐 v20.20.2
- npm 包管理器

## 📥 安装部署
### 1. 拉取代码
```bash
git clone 你的仓库地址
cd PixelVerse---Wplace
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动服务
```bash
node server.js
```

### 4. 访问网页
```
你的服务器ip:3000
```
服务启动成功后，浏览器访问该地址即可进入像素涂鸦画布。

## 🚀 服务器部署
### 方式1：直接后台运行
```bash
node server.js
```

### 方式2：PM2 守护进程（推荐生产环境）
```bash
# 安装pm2
npm install pm2 -g
# 启动项目
pm2 start ecosystem.config.js
# 设置开机自启
pm2 startup
pm2 save
```

## 📝 注意事项
1. 默认端口可在 `server.js` 内修改，注意服务器安全组放行端口
2. 画布数据会持久化保存，重启服务不会丢失像素画面
3. 公网部署建议配置反向代理 + SSL证书实现 HTTPS 访问
4. 房间、等级、涂鸦币、签到相关数据依赖持久化存储，否则服务重启后用户数据会丢失
